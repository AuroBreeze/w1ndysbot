# AIBanWords

使用硅基流动兼容接口和 Qwen 模型审核群内纯文本消息，识别广告营销、恶意引流、低俗赌博及恶意链接。模型判定违规后，机器人会撤回原消息、在群内警告并尝试发送飞书告警。

## 配置

在项目根目录 `.env` 中配置：

```dotenv
SILICON_FLOW_API_KEY=你的硅基流动API密钥
# 可选，默认使用已验证可用的 Qwen/Qwen3.5-9B
AIBANWORDS_MODEL=Qwen/Qwen3.5-9B
```

修改配置后需要重启机器人。未配置密钥、接口失败或结果无法解析时，模块按安全消息处理并记录错误日志。

## 使用

- 系统管理员在目标群发送 `aibw` 开启或关闭审核。
- 发送 `aibwmenu` 查看模块菜单。

开启后仅审核长度超过 10 个字符且不含 CQ 码的普通成员纯文本消息；群主、群管理员、系统管理员、图片和其他 CQ 消息会被跳过。

## 模型

默认模型为 `Qwen/Qwen3.5-9B`。旧默认模型 `Qwen/Qwen2-7B-Instruct` 已被硅基流动停用，因此不再使用。可以通过 `AIBANWORDS_MODEL` 覆盖默认模型，以适应服务端模型上下架变化。
